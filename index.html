Блокировки и долгие транзакции в PostgreSQL Проверено на PG 14–17 
-- Активные запросы старше 5 секунд и их блокирующие PID
SELECT
  a.pid,
  now() - a.query_start AS duration,
  a.state,
  pg_blocking_pids(a.pid) AS blocked_by,
  left(a.query, 120) AS query_preview
FROM pg_stat_activity a
WHERE a.state <> 'idle'
  AND now() - a.query_start > interval '5 seconds'
ORDER BY duration DESC;

Сделано под ежедневные задачи разработки и эксплуатации

Вместо разрозненных заметок в Notion, старых веток в Slack и устаревших ответов на форумах команда получает единый версионируемый реестр рабочих решений.

Поиск по коду и параметрам

Индекс понимает синтаксис флагов CLI, названия таблиц системных каталогов, коды ошибок HTTP и регулярные выражения.

Версии и откат без конфликтов

Каждая правка сниппета создаёт ревизию с диффом и комментарием: видно, что изменилось после обновления Kubernetes или Postgres.

Командные пространства

Разделяйте публичную базу знаний и внутренние runbook-и сервиса с правами доступа на уровне проекта и роли.

Синхронизация с GitHub

Храните критичные шпаргалки в Git-репозитории: изменения из merge request автоматически обновляют карточки в Patchbay.

Плагин для VS Code

Ищите и вставляйте сниппеты через Command Palette, не выходя из редактора. Поддерживается подстановка переменных.

HTTP API и CLI-клиент

Забирайте актуальные команды в CI-пайплайны или терминал одной командой patchbay get.

Один запрос — из терминала, редактора или браузера

Не обязательно открывать браузер во время разбора алерта. Через CLI или REST API можно сразу получить нужную версию сниппета и переменные окружения.

Подробные примеры эндпоинтов, заголовков авторизации и фильтров смотрите в разделе документации.
