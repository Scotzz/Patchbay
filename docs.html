Документация Patchbay

Справочник по CLI-клиенту, настройке интеграций и HTTP API v1 для встраивания в пайплайны и внутренние порталы.

Быстрый старт и CLI

CLI распространяется как единый статический бинарный файл под Linux, macOS и Windows, а также через Homebrew и npm. После установки привяжите локальный профиль к вашему токену доступа.

bash — установка и первая выборка 
# Установка через Homebrew или npm
brew install patchbay/tap/patchbay
# или: npm i -g @patchbay/cli

# Авторизация через токен из профиля
patchbay auth login --token "$PATCHBAY_TOKEN"

# Получить сниппет в stdout и скопировать в буфер
patchbay get pg-lock-check --runtime pg16 --copy

Версии и проверка сред

Каждый сниппет поддерживает произвольное число ревизий. Поле runtime фиксирует, на каких версиях СУБД, оркестратора или языка код проверялся последний раз. При появлении несовместимого флага заводится новая минорная или мажорная версия, а старая остаётся доступной по явному параметру ?version=.

Синхронизация с GitHub

Чтобы команда могла ревьюить runbook-и через привычные Pull Request, добавьте в корень репозитория файл .patchbay.yml и установите GitHub App на нужные репозитории.

yaml — конфигурация .patchbay.yml 
workspace: backend-core
default_visibility: team
sync:
  - path: "docs/snippets/**/*.sql"
    tags: ["postgres", "migration"]
    runtime: "pg16"
  - path: "scripts/oncall/*.sh"
    tags: ["incident", "bash"]
    require_review: true

Расширение VS Code

Установите расширение patchbay.patchbay-vscode из Marketplace. Нажмите Ctrl+Shift+P (или Cmd+Shift+P на macOS), выберите Patchbay: Insert Snippet и введите часть названия или тег. Если в сниппете объявлены переменные, редактор последовательно запросит их значения и вставит готовый блок.

Авторизация и лимиты

Все запросы к закрытым пространствам должны передавать персональный или сервисный токен в заголовке Authorization: Bearer <token>. Заголовки X-RateLimit-Remaining и X-RateLimit-Reset возвращаются в каждом ответе.

Получение сниппета (GET)

GET https://api.patchbay.dev/v1/snippets/{slug}

Возвращает содержимое сниппета, актуальную версию, список переменных и дату подтверждения совместимости. Необязательный query-параметр runtime подбирает наиболее свежую ревизию под указанную среду.

bash — пример запроса через curl 
curl -sS -X GET \
  "https://api.patchbay.dev/v1/snippets/pg-lock-check?runtime=pg16" \
  -H "Authorization: Bearer pb_live_98c4a1e7d2" \
  -H "Accept: application/json"
json — ответ 200 OK 
{
  "id": "snp_01J9M4Q7K2",
  "slug": "pg-lock-check",
  "workspace": "backend-core",
  "version": "2.4.0",
  "language": "sql",
  "runtime": ["pg14", "pg15", "pg16", "pg17"],
  "verified_at": "2026-10-19T11:20:00Z",
  "author": "d.krasnov",
  "content": "SELECT pid, now() - query_start AS duration, pg_blocking_pids(pid) FROM pg_stat_activity WHERE state <> 'idle';"
}

Коды ответов и ошибок

Код Идентификатор Причина и действие
401 unauthorized Отсутствует или отозван Bearer-токен. Выпустите новый токен в настройках профиля.
403 workspace_forbidden У токена нет прав чтения выбранного командного пространства.
404 snippet_not_found Сниппет с таким slug или запрошенной версией не существует.
429 rate_limit_exceeded Превышен суточный лимит тарифа. Повторите запрос после времени из Retry-After.
