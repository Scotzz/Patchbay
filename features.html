Возможности платформы

Каждый модуль Patchbay решает конкретную инженерную проблему: найти рабочий код за секунды, зафиксировать совместимость с версией среды и синхронизировать базу с Git.

Поиск по сниппетам и флагам

Полнотекстовый движок индексирует тело кода, флаги командной строки, имена системных представлений и сообщения об ошибках. Можно фильтровать выдачу по языку, runtime-версии и статусу проверки.

Поддерживаются точные фразы в кавычках и исключения через минус, чтобы не пролистывать десятки нерелевантных заметок.

lang:sql runtime:pg16 verified:true
bash — поиск через CLI 
# Найти проверенные команды для отладки TLS-сертификатов
patchbay search "openssl s_client" --tag tls --verified

# Результат:
# [1] tls/check-chain-expiry     openssl x509 -enddate (v1.4)
# [2] tls/verify-san-hostnames   openssl s_client -servername (v2.0)

Версионирование кода и матрица сред

Сниппеты редко живут в вакууме: флаг, работавший в Docker Compose v1, ломается в v2, а поведение функции PostgreSQL меняется между 13 и 16 версиями.

В Patchbay каждая правка создаёт отдельную ревизию с diff-просмотром и пометкой поддерживаемых версий. Старые варианты не удаляются — их можно открыть для поддержки legacy-кластеров.

semver diff view changelog
yaml — заголовок метаданных сниппета 
id: k8s/drain-node-safely
version: 2.3.0
runtime:
  kubernetes: ">=1.27 <=1.31"
verified_at: 2026-10-14
author: m.tarasova
variables:
  - name: NODE_NAME
    description: Имя узла из kubectl get nodes

Командные пространства и права доступа

Разделяйте личные черновики, публичные шпаргалки и закрытые пространства для команд SRE, Backend или QA. На уровне каждого пространства задаются роли: чтение, ревью, публикация и управление токенами.

Для онбординга новых инженеров можно собрать подборку обязательных runbook-ов по конкретному сервису.

RBAC Audit Log SSO / SAML
json — структура прав пространства 
{
  "workspace": "core-payments-sre",
  "visibility": "private",
  "policies": {
    "require_review_before_verify": true,
    "allow_api_tokens": ["ci-readonly", "oncall-cli"],
    "retention_days": 365
  }
}

Интеграции с GitHub и VS Code

Подключите репозиторий в GitHub, чтобы хранить критичные SQL-запросы и скрипты рядом с кодом сервиса. После слияния PR вебхук автоматически обновляет сниппеты в Patchbay и сохраняет ссылку на коммит.

В VS Code расширение открывается по Ctrl+Shift+P, подставляет переменные шаблона и вставляет код прямо в позицию курсора.

GitHub App VS Code Extension Webhook Sync
yaml — .patchbay.yml в корне репозитория 
workspace: platform-infra
sync:
  - path: "runbooks/postgres/*.sql"
    tags: ["postgres", "incident"]
    visibility: team
  - path: "scripts/k8s/*.sh"
    tags: ["kubernetes", "ops"]
    require_ci_check: true
